# Episode production guide

How a clawduh episode is made, start to finish. Episode 004 (`video/src/episodes/004-leave-early/`) is the reference
implementation; read it before you start.

## 1. House style

- **Look:** flat 2D vector cartoon, crude / creepy / hilarious. Thick dark outlines (`INK = "#140d0b"`, 4–8 world px),
  muted slightly dirty palettes, grime and stains, flies, sweat, bloodshot veins, crooked yellow teeth, dead-eyed stares,
  bags under eyes. Dark-humour sight gags in the set dressing (signs, posters, labels).
- **The engine adds the rest automatically:** hand-drawn line boil, film grain, vignette, light flicker, a per-shot colour
  grade, and TikTok-style word-highlight captions generated from the timeline.
- **Characters are always original.** A reference video is only for understanding who speaks and what happens — never copy
  its character designs, outfits, colours or branding. Give each episode its own cast, set and palette so episodes look
  distinct from each other (YouTube's "inauthentic content" policy punishes templated uploads).
- **Every episode ships in two formats:** `ep<id>` (1920×1080) and `ep<id>-vertical` (1080×1920), both from the same shots.

### Hard rules
1. **No voice / audio credit text anywhere in the video** — no "voice: …", no creator or channel names, no "audio by".
   (A title card at the end is fine.) Don't put audio credits in the repo either; the uploader adds them on the platform.
2. **Never commit third-party audio or video.** `episodes/*/source/` and `video/public/episodes/*/audio.*` are git-ignored;
   keep it that way.
3. Lip-sync must land on the character who is actually speaking (see §4). Build timelines with `--mouth auto` (§3)
   instead of hand-rolling per-episode mouth fixes.

## 2. Layout

```
episodes/<id>/                 README (cast, speaker notes, status, render steps, upload kit), preview.jpg, speakers.json
  analysis/                    transcript.json (whisper words), mouth_cues.json (Rhubarb), dialog.txt
  source/                      audio (git-ignored): original, audio_16k_mono.wav, audio_full.wav, reference.mp4
video/src/episodes/<id>/
  index.ts                     EpisodeDef (id, title, timeline, shots, tail, speakerFocus)
  shots.tsx                    the direction: shot list (cue()-anchored), per-shot cameras, 9:16 reframes
  timeline.json                generated by pipeline/build_timeline.py — never hand-edit
  <sets>.tsx, cast/*.tsx       episode sets, cutaways and characters
video/src/episodes/index.ts    registry: each episode -> compositions ep<id>, ep<id>-vertical
video/public/episodes/<id>/audio.wav   (git-ignored) what Remotion plays
```

## 3. Pipeline (audio → timeline)

```bash
pipeline/fetch_audio.sh <file-or-url> episodes/<id>      # source/ + video/public/episodes/<id>/audio.wav
python3 pipeline/transcribe.py episodes/<id>             # analysis/transcript.json (faster-whisper, word timings)
pipeline/lipsync.sh episodes/<id>                        # analysis/mouth_cues.json (Rhubarb, mouth shapes A–H, X)
# write episodes/<id>/speakers.json (see §4), then:
python3 pipeline/build_timeline.py episodes/<id> --mouth auto   # -> video/src/episodes/<id>/timeline.json, prints every line
```
(`pipeline/run_episode.sh episodes/<id>` runs the last three steps, with `--mouth auto`.)

`speakers.json`:
```json
{ "cast": { "dale": "Dale - ..." },
  "turns": [ { "at": "first words of the turn", "speaker": "dale" }, { "from": 12.4, "speaker": "chet" } ] }
```
- Each turn starts where its `at` phrase is spoken (searched in order, after the previous turn; an exact match wins over
  a look-alike; words are assigned to speakers by order, not timestamp). Use 3–6 distinctive words. `from` (seconds) is
  the fallback for impossible cases.
- **Read the printed line list after every build** and fix anchors until every line is on the right speaker.
- One speaker? A single turn is enough.

### Mouth shapes: `--mouth auto` (use it for every new episode)
Rhubarb reads mouth shapes off the whole mix. On clean dialogue that's the most accurate source, but it fails when
**music sits under the dialogue** (it finds ~2–3 mouth changes a second instead of 5–8, and opens the mouths on the
music) and on **whispered words** (left shut). `--mouth auto` (`pipeline/voice.py`) measures the voice itself every
10 ms (stereo centre minus sides, minus the music bed, 300–4000 Hz) and, per talking stretch:
- keeps Rhubarb where the voice stands clear of the music and Rhubarb kept up;
- rebuilds the stretch from the voice's loudness (how open) + the word's spelling (which shape) where the line sits on
  music (less than 14.5 dB above the floor) or Rhubarb gave up (under 2.5 changes/s);
- opens whispered words Rhubarb left shut (quiet but audible, at least 0.2 s) from the voice, moderately.

The build prints what it did, e.g. `mouth (auto): 19 of 24 talking stretches from the voice level (music under the
line: 18 ...)`. Default `--mouth rhubarb` reproduces old timelines byte for byte; `--mouth envelope` uses the voice
everywhere. Measured on the episodes that needed per-episode fixes before this existed:

| | Rhubarb only | `--mouth auto` | the episode's own fix |
|---|---|---|---|
| 010 "now" half, mouth changes/s | 2.5 | 4.3 | 7.8 (frame-by-frame) |
| 010 "now" half, agreement with its hand-built track (correlation) | −0.11 | +0.62 | — |
| 009, agreement with its voice-driven rig | +0.15 | +0.44 | — |
| 005, whispered words opened | 0 | 21 | spelling for every shut word |
| clean episodes (001/003/004/006/008), agreement with Rhubarb | — | 0.95–0.98 | — |

`--retime-words` (optional): Whisper often stretches a word back over the silence before it (or a breath), so its
caption and mouth start early. This moves such starts (and clearly over-long ends) to where the voice really is,
walking back through s/sh/f hiss. It prints every change (`retimed The@48.18: start -> 50.14`); check them on long
pauses or music-backed episodes, where it helps most.

## 4. Speaker identification (do this properly — it's the most important correctness step)

1. Read the whole transcript (`analysis/transcript.json` segments + words). Write down every line and who says it based on
   meaning: who asks, who answers, who is being addressed, running jokes, who is the victim/instigator.
2. **If there is a reference video** (`source/reference.mp4`): sample frames (`ffmpeg -i ... -vf fps=0.5,scale=240:-1`)
   into labelled contact sheets, then 1–2 fps around every ambiguous line. Note who is on camera, whose mouth is open,
   gestures and reactions. Krumbl3D-style edits often cut to the listener, so weigh meaning + visuals together.
3. **Audio check** (essential for audio-only episodes): one actor often voices every character, so pitch alone lies.
   Compare per-line timbre: mean MFCCs (librosa, n_mfcc=20, drop c0, voiced frames only) per line → centroids from lines
   you're sure about → nearest-centroid for ambiguous lines (validate with leave-one-out on the sure lines). Also look at
   median pitch and the loudness envelope between lines (sound effects, pauses, straining).
4. Decide, write `speakers.json`, build, verify the printed lines. Record the close calls and reasoning in the episode
   README ("Speakers" section).

## 5. Engine reference

- **Stage** (`engine/Stage.tsx`): world space 1920×1080 at zoom 1. `Cam = { x, y, zoom, rot? }` (centre + zoom).
  `camLerp(a, b, k)`, `camPath(keys, local, ease)`, `shake(frame, amp)`. `<Stage cam frame shakeAmp overlay>` draws the
  world with line boil. Overlays: `LightWash` (radial light), `ScreenFlash`.
- **Shot context** — `useEpisode()` → `{ timeline, shot: { t, frame, fps, start, end, local, p } }` (`t` absolute s,
  `local` seconds into the shot, `p` 0..1 through the shot).
- **Timeline** (`engine/timeline.ts`): `mouthAt(tl, speaker, t)`, `isTalking(tl, speaker, t)`, `energyAt(tl, t)`,
  `lineAt(tl, t)`, `cue(tl, phrase, { edge: "start"|"end", after, offset })` → seconds of the first exact match after `after`.
  Speech hook pattern (mouth on twos):
  ```ts
  const tq = onN(shot.frame, 2) / shot.fps;
  { mouth: mouthAt(timeline, "dale", tq), talking: isTalking(timeline, "dale", shot.t), energy: energyAt(timeline, shot.t) }
  ```
- **ShotDef** (`engine/EpisodePlayer.tsx`): `{ name, start, end, render: () => <Comp />, grade?, filter?, transition?,
  portrait? }`. `render` must return JSX of a component (hooks live inside components, never call a hook-using function
  directly as `render`). Grades: `night` (default), `memory`, `hell`, `heaven`, `cave`, `fluoro`, `none`; or a custom CSS
  `filter` string per shot. Transitions: `cut`, `flash`, `static`, `fade`, `slam`, `redflash`.
- **Portrait reframe** `portrait: { zoom?, x?, y?, dx?, dy? }` — `zoom` multiplies the shot camera's zoom (1 = same world
  scale, a 1080-wide slice); `x` = world x, `"speaker"` (follows `speakerFocus` of whoever talks) or `(local) => x`.
- **EpisodeDef** (`engine/episode.tsx`): `{ id, title, timeline, shots, tail?, speakerFocus? }` — `tail` = seconds held after
  the audio for a silent ending.
- **util** (`engine/util.ts`): `lerp, clamp, prog(t,a,b), easeInOut, easeOut, easeIn, easeOutBack, onN, rnd(seed),
  rndRange, smoothPath(pts, closed, tension), blob(...), cloudPath(...), scribble(...), limb(origin, angles, lengths)`.
- **parts** (`characters/parts.tsx`): `INK, DLine, Eye, Mouth, Flies, Shadow, StinkLines, blinkAmount, saccade,
  taperPath`.
- **Best rig examples:** `characters/Possum.tsx`, `Raccoon.tsx`, `Vulture.tsx` (004), `Cat.tsx` (003), `TallFigure.tsx`.

## 6. Character rigs

- Origin = floor between the feet (or the seat for a sitting character); faces **right** by default; `flip` mirrors.
  **Text inside a flipped character renders mirrored** — counter-flip it:
  `<g transform={flip ? \`translate(${2 * cx} 0) scale(-1 1)\` : undefined}><text x={cx} …/></g>`.
- Props: `id, x, y, scale, flip, t, frame, mouth, talking, energy, expr, look, headTilt` + pose/state props
  (arm angles via `limb()`, holding props, special states like sick/strain/soiled).
- Expressions as a preset table (lid top/bottom/angle, pupil, smile, brows). Blink with `blinkAmount`, eye darts with
  `saccade`, head bob/tilt when talking, motion on twos (`onN(frame, 2)`).
- Mouth: `parts.Mouth` (shapes A–H, X) or a custom equivalent (e.g. a hinged beak). Keep mouths visible in close-ups
  (props must not cover them).
- Export the head offset (e.g. `export const DALE_HEAD: Pt = [14, -402]`) for camera presets and `speakerFocus`.
- New characters for an episode go in **its own folder** (`video/src/episodes/<id>/cast/`), not in `src/characters/`.

## 7. Directing

- One world per set, many cameras: define presets (`wide`, `two`, `cu<Name>`, `ecu<Name>`, `ms<Name>`) from the head
  positions. A scene wrapper component draws the set + cast with per-shot overrides (see `004/grill.tsx` `GrillScene`).
- Anchor every shot to the script with `cue()` (constants object `T`), keep shots in order, ~0.5–4 s each, cutting on
  speaker changes with reaction shots between. Lines that describe something get a cutaway gag (004: office fish,
  printer-room khakis, wall of shame). Silent stretches need visual gags. Give it a strong silent punchline in the `tail`.
- Continuity is driven by the clock (functions of `t`: stains spread, signs flip, fog rolls in).
- 9:16: every shot gets a `portrait` reframe. Close-ups: `x` at the head. Wides: follow the speaker/action with
  `zoom ≥ 1` and `y` on the characters (otherwise the frame is mostly floor and ceiling).

## 8. Review loop (mandatory, both formats)

From `video/`:
```bash
npx tsc --noEmit -p .                                              # must be clean
LIST=1 COMP=ep<id> node scripts/stills.mjs                         # resolved shot table — check order and lengths
COMP=ep<id> OUT=out/<id>/stills node scripts/stills.mjs            # one still per shot (debug label), then:
python3 scripts/contact_sheet.py out/<id>/stills out/<id>/sheets   # look at EVERY sheet
COMP=ep<id>-vertical OUT=out/<id>/stills_v node scripts/stills.mjs && python3 scripts/contact_sheet.py out/<id>/stills_v out/<id>/sheets_v
DEBUG=0 COMP=ep<id> OUT=out/<id>/x node scripts/stills.mjs 123 456 # specific frames, no debug overlay
```
Check every shot: the right character's mouth moves on each line; nobody is awkwardly cut off by the frame; no mirrored
text; **no voice-credit text**; props don't cover mouths; expressions read; key action isn't hidden behind captions; gags
read instantly; mid-motion frames look right. Fix and repeat until it's genuinely good.

## 9. Performance

This container renders on CPU. Avoid per-frame `feTurbulence`, big `feGaussianBlur`s and large filter regions (they are
10× slower). Prefer gradients, opacity, blend modes, pre-computed shapes (`useMemo`) and simple paths. Psychedelic effects:
animate hue via the shot `filter` (`hue-rotate(...)` from `shot.t`), gradients, rotating shapes, kaleidoscopic
`<use>` copies — not turbulence. Aim for ≲1.5 s per still in this container.

## 10. Done means

- `episodes/<id>/`: README (cast, set, speaker notes + close calls, status, render steps, upload kit **without** audio
  credit), `preview.jpg` (3×3 sheet of 9 key moments, rendered with `DEBUG=0`), `speakers.json`, `analysis/`.
- `video/src/episodes/<id>/`: index.ts, shots.tsx, timeline.json, sets/cast; registered in `video/src/episodes/index.ts`.
- `npx tsc --noEmit` clean; stills reviewed in both formats.
- Full MP4 renders: `cd video && npm run render -- <id>` → `renders/<id>/<id>_{landscape_1920x1080,vertical_1080x1920}.mp4`.
